    How it works and its limits

    A YOLO11n detector finds every bird, then a MobileNetV2 classifier names each one. Birds below 50% confidence are listed as unidentified with the model's best guesses.

    • This test build knows 50 species. Birds outside that list get the closest wrong answer.
    • Dense flocks are undercounted; tile scanning helps with large photos.
    • Distance, common names and species notes appear once the species knowledge base is built.
